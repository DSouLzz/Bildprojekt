# Mitt bild projekt

Version 0.2.0

En enkel AI-bildeditor med dra/släpp, markering, klipp/kopiera, klistra som lager, lager, ångra/gör om, export och GitHub-baserad versionskontroll.

Repository: https://github.com/DSouLzz/Bildprojekt

## Starta
npm install
npm run dev

## Release/update
Appen kontrollerar GitHub Releases vid start. Desktop-autoupdatering med signerad installationsfil läggs ovanpå denna kontroll i nästa steg.
